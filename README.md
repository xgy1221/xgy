# 学管云 · 培训机构多角色微信小程序

面向培训机构的微信小程序原型，覆盖五类角色：

| 角色 | 说明 | 核心能力（首版） |
|------|------|------------------|
| 学生 / 家长 | 学员侧，家长代管为主 | 一号多孩切换、课程、课表、待办 |
| 授课老师 | 教学执行 | 班级、学员、今日课次 |
| 教务 | 教务运营 | Excel/CSV 导学员、排课、报名 |
| 合伙人 | 单人/多人合伙 | 业绩、分成、团队 |
| 管理员 | 系统管理 | 账号多角色、组织、设置 |

## 本地运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本仓库根目录（已配置 `miniprogramRoot: miniprogram/`）
3. AppID 可先用测试号 / `touristappid`
4. 编译后在登录页点快捷账号体验各角色

## 学员导入（Excel）

业务约定：

- 初始录入走 Excel：字段含 **学生姓名、家长手机号、家长姓名、年级、校区、备注**
- **多个学生可以对应同一个家长手机号**（一户两个小孩）
- 家长用该手机号登录后，可在首页 /「我的」切换孩子，课程与课表跟随当前学员变化

模板文件：`miniprogram/assets/templates/学员导入模板.csv`  
（用 Excel 打开编辑后「另存为 CSV」即可导入）

教务端路径：首页 → **Excel 导入学员**

- 支持选择 CSV 文件导入
- 支持「加载演示 Excel 数据」（含同手机号两孩示例）
- 导入结果按家长手机号自动分组预览

## 目录结构

```
miniprogram/
  app.js / app.json / app.wxss
  assets/templates/    # 学员导入模板
  components/          # 底部导航、统计卡片等
  pages/               # 按角色分目录（含 academic/import）
  services/
    mock.js            # 演示登录与课表
    students.js        # 学员库 / 导入 / 家庭分组
  utils/               # 角色常量、鉴权、CSV 解析
project.config.json
```

## 设计说明

- 一人可绑定多个角色，登录后选择身份；「我的」可再次切换
- 家长账号按手机号关联学员列表，与角色权限相互独立
- 各角色独立导航（自定义底部栏），互不混用 Tab
- 当前为前端 Mock，无后端依赖；后续可替换为真实 API 与服务端解析 xlsx
