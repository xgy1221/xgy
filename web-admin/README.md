# 学管云 Web 管理端

给**教务 / 合伙人 / 管理员**用的电脑后台（与微信小程序共用一套业务模型）。

## 和小程序怎么分工

| 能力 | Web 管理端 | 微信小程序 |
|------|------------|------------|
| 创建教案（含多少节课、售价） | ✅ | 查看 |
| 录入学员 / 家长手机号 | ✅ | 家长自助 / 教务代录 |
| 教师管理 | ✅ | 老师看自己班级 |
| 创建班级、加固定班学员、日历订课 | ✅ | 老师/家长按日历上课 |
| 临时补课、下课评价消课 | | ✅ |
| 财务：实收 / 退费 / 待收 / 分成 | ✅ 合伙+管理 | 仅指标快览 |
| 账号多角色授权 | ✅ 仅管理 | 只读名单 |

当前为前端本地演示（`localStorage` key：`xgy_web_admin_v3`，含 `orgId` 多机构隔离）；以后接同一套后端即可与小程序数据打通。

## 启动

```bash
cd web-admin
npm install
npm run dev
```

浏览器打开提示地址，在登录页选择角色进入。

## 角色权限（菜单差异）

| 模块 | 教务 | 合伙人 | 管理员 |
|------|------|--------|--------|
| 学员 / 教师 / 课程 / 教案 | 编辑 | 只读（本校区） | 编辑 |
| 财务中心 | 无 | 本校区 + 分成 | 全校区 |
| 账号权限 | 无 | 无 | 有 |

演示账号：

- `13800000003` 赵教务  
- `13800000004` 陈合伙人（城南校区，分成 15%）  
- `13800000000` 周总（管理员）  

## 模块

1. **工作台**：按角色展示运营 KPI；合伙/管理额外有财务摘要  
2. **学员管理**：按家长手机号建学员档案  
3. **教师管理**：师资档案与校区  
4. **课程管理**：建班 + 日历订课（指定授课老师与时间）  
5. **教案管理**：课次数、售价、上架（销售产品）  
6. **财务中心**：签约/实收/退费/待收；按校区、按教案；订单流水；合伙人分成  
7. **账号权限**（管理员）：员工多角色列表
