# 学管云 Web 管理端

给**教务 / 销售**用的后台（不在小程序里）。

## 和小程序怎么分工

| 能力 | Web 管理端 | 微信小程序 |
|------|------------|------------|
| 创建教案（含多少节课、售价） | ✅ | 查看/上架状态同步（后续 API） |
| 录入学员 / 家长手机号 | ✅ | 家长也可自助补全 |
| 创建班级、加固定班学员 | ✅ | 老师看班级花名册 |
| 日历订课、指定授课老师 | ✅ | 老师/家长按日历上课 |
| 临时补课、下课评价消课 | | ✅ |
| 课次评价总览 | 可后续同步 | 教务端可查看 |

当前为前端本地演示（`localStorage`），方便先把流程跑通；以后接同一套后端即可与小程序数据打通。

## 启动

```bash
cd web-admin
npm install
npm run dev
```

浏览器打开终端提示的本地地址，点「教务身份进入」。

## 模块

1. **教案管理**：创建/编辑教案，设置课次数与售价  
2. **学员管理**：按家长手机号建学员档案  
3. **班级管理**：建班、绑教案与默认老师、加/移学员  
4. **日历订课**：选日期 → 选班级 → 指定老师与时间
