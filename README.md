# 学管云

培训机构运营体系原型，分两块：

1. **微信小程序**（`miniprogram/`）：家长 / 老师 / 教务现场为主；合伙、管理员可登但只看轻量看板  
2. **Web 管理端**（`web-admin/`）：教务 / 合伙人 / 管理员——教案、学员、教师、课程、财务（按角色）  

产品说明与角色分权见 [`docs/PRODUCT.md`](docs/PRODUCT.md)。

## 分工

| 能力 | Web 管理端 | 微信小程序 |
|------|------------|------------|
| 创建教案（课次数、售价） | ✅ 教务/管理可编；合伙只读 | 查看 |
| 学员 / 教师档案 | ✅ | 代录 / 家长自助 / 老师花名册 |
| 建班、日历订课 | ✅ | 家长/老师上课日历 |
| 临时补课、下课评价消课 | | ✅ |
| 财务（实收/退费/分成） | ✅ 合伙+管理 | 合伙/管理仅快览指标 |
| 账号权限 | ✅ 仅管理 | 管理端只读列表 |
| 多机构隔离 | ✅ 员工按 `orgId` | ✅ 员工按机构；家长可跨机构看孩子 |

## 多机构说明

- 业务数据带 `orgId`：学员、教案、班级、课次、订单、白名单互不串台  
- 员工账号绑定一家机构；管理员也只管理**本机构**（不是平台超管）  
- 家长 `13800000001` 同时在「学趣思维」「启航英语」有孩子，切换学员即切换机构  
- 本地演示升 schema / Web `xgy_web_admin_v3` 会重种子，避免旧数据无 orgId 泄漏

## 微信小程序

1. 用微信开发者工具导入仓库根目录（`miniprogramRoot` 已配置）  
2. AppID 可用测试号 / `touristappid`  
3. 登录页快捷账号，或任意手机号体验家长引导  

**主用角色：** 学生/家长、老师、教务。  
**合伙 / 管理员若登录：** 看业绩或全校运营快览，文案会引导去 Web 做对账与配置。

**日历课表：** 绿=已上，橙=未上。老师可搜索姓名/手机号临时加学员（不改原班）。老师评价学生后消课；学生评老师可选。
