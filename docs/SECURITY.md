# 学管云安全基线

## 已落地

| 能力 | 说明 |
|------|------|
| JWT + Redis 黑名单 | 登出 / 切角色会使当前 Token 失效 |
| 登录限流 | 每手机号 / IP 滑动窗口（Redis） |
| 白名单注册 | 新家长手机号须先在教务白名单，禁止任意号自注册 |
| 角色鉴权 | 家长禁止课堂写操作；老师仅可操作自己的课；报读/白名单/活动写操作限教务或管理员 |
| CORS 白名单 | 默认仅本机 Vite 端口，不再 `*` |
| 密钥外置 | `JWT_SECRET` / `DB_*` / `REDIS_*` / `SMS_DEMO_CODE` 支持环境变量 |
| 审计日志 | 登录、授权、录单等写入 `audit_logs` |
| JWT 解析容错 | 无效 Token 不再打 500 |

## 上线前必做

1. 设置强随机 `JWT_SECRET`（≥32 字节）
2. 更换 MySQL / Redis 密码，禁止把演示密码用于生产
3. 关闭或替换固定短信码：接入真实短信网关后清空 `SMS_DEMO_CODE` 并校验真实验证码
4. 配置 `app.security.cors-allowed-origins` 为正式 Web 域名
5. 仅内网或网关后暴露管理端；小程序合法域名配置 HTTPS API

## 仍建议迭代

- 真短信 + 图形验证码
- 多端登录踢下线（会话版本号）
- 操作二次确认（大额退费等）
- WAF / 网关层限流与监控告警
