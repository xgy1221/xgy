# 学管云 · 培训机构多角色微信小程序

面向培训机构的微信小程序原型。产品分层说明见 [`docs/PRODUCT.md`](docs/PRODUCT.md)。

## 核心业务怎么跑

```text
家长手机号（账号）
  └─ 多个学员
       └─ 多个教案报读（课程包 + 剩余课次）
```

**建档方式：**

1. **在读学员（主路径）**：老师 / 教务代录——手机号建档、绑教案、改剩余课次  
2. Excel 批量导入，或只录家长手机号白名单  
3. 新客家长自助：未建档登录后三步引导  

原则：已经在上课的由机构弄好；家长打开即可查看。 

## 角色一览

| 角色 | 核心能力 |
|------|----------|
| 学生 / 家长 | 引导入驻、一号多孩、选教案、看剩余课次/课表 |
| 授课老师 | 班级、学员、今日课次 |
| 教务 | 手机号白名单、Excel 导入、教案管理、排课报名 |
| 合伙人 | 业绩、分成、团队 |
| 管理员 | 账号、组织、设置 |

## 本地运行

1. 安装微信开发者工具，导入本仓库根目录  
2. AppID 可用测试号 / `touristappid`  
3. 编译后点登录页快捷账号，或输入任意 11 位手机号体验家长引导  

## 推荐体验路径

| 手机号 | 体验点 |
|--------|--------|
| `13800000001` | 已有两孩 + 已报读教案 |
| `13800000031` | 机构只录了手机号 → 走引导补学员/教案 |
| 任意新号如 `13900001234` | 自动新建家长账号 → 完整三步引导 |
| `13800000003` | 教务：白名单 / Excel / 教案管理 |
| `13800000004` | 合伙人+教务+老师；「我的」切换，默认上次角色 |
| `13800000000` | 周总多角色（合伙/管理/教务/老师） |

## 教案（课程产品）

教务端「课程」页维护教案：名称、课次数、价格、大纲、上架状态。  
家长在引导第 3 步或「我的教案」里勾选已购教案，生成报读（剩余课次 = 教案课次数）。

模板：`miniprogram/assets/templates/学员导入模板.csv`
