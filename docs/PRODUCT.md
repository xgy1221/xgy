# 产品说明

## 定位

学管云 = 多租户教培 SaaS。第一版只卖一条链：

```
白名单开通家长 → 代录学员/报读 → 建班排课 → 上课下课 → 评价消课 → 财务看账
```

## 角色

| 角色 | 端 | 能力 |
|------|----|------|
| PARENT | 小程序 | 看自己孩子课表、评价老师、比赛报名 |
| TEACHER | 小程序 | 自己的课：下课、旷课、评价消课、临补 |
| ACADEMIC | Web（小程序可轻量） | 学员/报读/白名单/排课/教案/活动 |
| PARTNER | Web | 本人渠道财务只读 |
| ADMIN | Web | 授权、全量财务、审计 |

## 硬规则

1. 所有员工写操作绑定 `orgId`  
2. 新家长必须先在机构白名单  
3. 老师只能操作自己的课次  
4. 消课：非旷课 + 有报读 → 剩余课时 -1（同一事务）  
5. 禁止双真相：Web / 小程序 / 后端共用同一 API  

## 不做（一期）

微信支付、订阅消息、作业相册、跨机构平台超管。
