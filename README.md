# 学管云 · 培训机构多角色微信小程序

面向培训机构的微信小程序原型，覆盖五类角色：

| 角色 | 说明 | 核心能力（首版） |
|------|------|------------------|
| 学生 / 家长 | 学员侧，家长代管为主 | 课程进度、课表、待办提醒 |
| 授课老师 | 教学执行 | 班级、学员、今日课次 |
| 教务 | 教务运营 | 课程、排课、报名跟进 |
| 合伙人 | 单人/多人合伙 | 业绩、分成、团队 |
| 管理员 | 系统管理 | 账号多角色、组织、设置 |

## 本地运行

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本仓库根目录（已配置 `miniprogramRoot: miniprogram/`）
3. AppID 可先用测试号 / `touristappid`
4. 编译后在登录页点快捷账号体验各角色

## 目录结构

```
miniprogram/
  app.js / app.json / app.wxss
  components/          # 底部导航、统计卡片等
  pages/               # 按角色分目录
  services/mock.js     # 演示数据与登录
  utils/               # 角色常量、鉴权会话
project.config.json
```

## 设计说明

- 一人可绑定多个角色，登录后选择身份；「我的」可再次切换
- 各角色独立导航（自定义底部栏），互不混用 Tab
- 当前为前端 Mock，无后端依赖；后续可替换 `services/mock.js` 为真实 API
