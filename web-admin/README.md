# 学管云 Web 管理端

给**教务 / 合伙人 / 管理员**用的电脑后台，与微信小程序、Spring Boot **共用同一后端**（JWT + MySQL）。

## 和小程序怎么分工

| 能力 | Web 管理端 | 微信小程序 |
|------|------------|------------|
| 创建教案（含多少节课、售价） | ✅ | 查看 |
| 录入学员 / 家长手机号 | ✅ | 家长自助 / 教务代录 |
| 教师管理 | ✅ | 老师看自己班级 |
| 创建班级、加固定班学员、日历订课 | ✅ | 老师/家长按日历上课 |
| 临时补课、下课评价消课 | | ✅ |
| 财务：实收 / 退费 / 待收 / 分成 | ✅ 合伙+管理 | 仅指标快览 |
| 账号多角色授权 | ✅ 仅管理 | 只读名单 |

## 启动

先启动后端（MySQL / Redis + Spring Boot `8080`），再：

```bash
cd web-admin
npm install
npm run dev
```

Vite 已把 `/api` 代理到 `http://localhost:8080`。浏览器打开提示地址。

登录：手机号 + 短信验证码（演示统一 **`123456`**）。登录页可点演示账号一键填入。

## 角色权限（菜单差异）

| 模块 | 教务 | 合伙人 | 管理员 |
|------|------|--------|--------|
| 学员 / 教师 / 课程 / 教案 | 编辑 | 只读（本校区） | 编辑 |
| 财务中心 | 无 | 本人渠道 + 分成 | 全校区 |
| 账号权限 | 无 | 无 | 有 |

演示账号：

- `13800000003` 赵教务 · 学趣思维  
- `13800000004` 陈合伙人 · 学趣思维（分成 15%）  
- `13800000000` 周总 · 学趣思维（管理员）  
- `13800000040` 启航教务 · **启航英语**（验证机构隔离）  

机构隔离由后端 JWT `orgId` 保证；学趣账号看不到启航数据，反之亦然。

## 模块

1. **工作台**：按角色展示运营 KPI；合伙/管理额外有财务摘要  
2. **学员管理**：按家长手机号建学员档案  
3. **教师管理**：师资档案与校区  
4. **课程管理**：建班 + 日历订课（指定授课老师与时间）  
5. **教案管理**：课次数、售价、上架（销售产品）  
6. **财务中心**：签约/实收/退费/待收；按校区、按教案；订单流水；合伙人分成  
7. **账号权限**（管理员）：员工多角色列表  

## 技术说明

- `src/api/client.js`：Bearer Token 请求封装  
- `src/auth/roles.js`：登录 / 切 Web 角色（ADMIN > PARTNER > ACADEMIC）  
- `src/data/store.js`：页面数据层，全部改为调用 `/api/*`（不再使用本地 `localStorage` 业务库）
