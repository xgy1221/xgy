# 学管云 · 产品结构建议

## 你真正要管理的 4 层东西

| 层级 | 叫什么 | 一句话 |
|------|--------|--------|
| 账号 | 家长手机号 | 谁能登录 |
| 档案 | 学员 | 家下面挂几个孩子 |
| 产品 | 教案 / 课程包 | 卖的是什么、含多少课次 |
| 报读 | 购买记录 | 哪个孩子买了哪个教案、还剩多少课 |

后面的排课、消课、请假、分润，都挂在「报读」上，不要一上来做成一张超级大表。

```text
家长手机号
  └─ 学员 A / 学员 B
       └─ 报读：教案X（总 48 课，剩余 32）
       └─ 报读：教案Y（总 24 课，剩余 24）
            └─ 排课课次 → 上课 → 消课
```

## 两种建档入口（并存）

1. **机构先录**  
   - Excel 完整学员信息，或  
   - 只录家长手机号（白名单）  
2. **家长自助**  
   - 授权登录后，若还没有学员 → 分步引导创建学员 + 选教案  
   - 若手机号从未录过 → 自动新建家长账号，再走同一套引导

## 教案（课程产品）建议字段

- 名称、适用年级、总课次数、售价、状态（上架/下架）
- 大纲课次列表（第 1 课 … 第 N 课，可选）
- 以后再加：教材版本、科类、校区适用范围

教务日常：上架教案 → 看谁报了 → 排课消课。  
家长日常：看自己孩子报了哪些教案、剩余课次、课表。

## 推荐家长引导步骤

1. 登录 / 授权手机号  
2. 填写家长称呼（可跳过）  
3. 添加至少两个孩子信息（可继续添加）  
4. 为每个孩子勾选已购教案（也可稍后在课程页补）  
5. 进入首页

## 以后课程管理怎么长

- **教案管理**：增删改教案、课次数、大纲  
- **报名/报读**：教务代录或家长自选；审核缴费状态  
- **排课**：从报读剩余课次里排  
- **消课**：上完课扣剩余；请假/旷课规则另配  

先把「手机号 → 多学员 → 多教案报读」跑通，比一次做完美排课更重要。
