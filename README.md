# 学管云

培训机构运营体系原型，分两块：

1. **微信小程序**（`miniprogram/`）：家长 / 老师 / 教务轻量查看、上课、临补、评价消课  
2. **Web 管理端**（`web-admin/`）：教务/销售主力后台——教案、学员、建班、日历订课  

产品说明见 [`docs/PRODUCT.md`](docs/PRODUCT.md)。

## 分工

| 能力 | Web 管理端 | 微信小程序 |
|------|------------|------------|
| 创建教案（含多少节课、售价） | ✅ | 可选查看 |
| 学员建档 | ✅ 主力 | 代录 / 家长自助 |
| 创建班级、加固定班学员 | ✅ | 老师看花名册 |
| 日历订课、指定老师 | ✅ | 家长/老师上课日历 |
| 临时补课、下课评价消课 | | ✅ |
| 课次评价总览 | 后续可同步 | 教务可查看 |

## Web 管理端

```bash
cd web-admin
npm install
npm run dev
```

进入后可用：教案管理 → 学员管理 → 班级管理 → 日历订课。详见 [`web-admin/README.md`](web-admin/README.md)。

## 微信小程序

1. 用微信开发者工具导入仓库根目录（`miniprogramRoot` 已配置）  
2. AppID 可用测试号 / `touristappid`  
3. 登录页快捷账号，或任意手机号体验家长引导  

**日历课表：** 绿=已上，橙=未上。老师可搜索姓名/手机号临时加学员（不改原班）。老师评价学生后消课；学生评老师可选。
